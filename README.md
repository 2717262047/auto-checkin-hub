## ✨ 具体功能

| 平台 | 自动完成的事 | 说明 |
| --- | --- | --- |
| **小黑盒** | 每日签到；分享任意帖子、分享游戏详情、分享游戏评价三项任务 | 接口超时自动换游戏/评价重试 3 次，整轮失败自动再跑一次；当天没补上的任务第二天自动只补这一项 |
| **网易云音乐** | 音乐人签到 + 每日签到 + 随机听歌任务 | 滑块验证失败自动转扫码登录，扫码最稳 |
| **微软 Bing** | 奖励页每日任务、拼图/quiz 类任务、搜索赚积分（默认 30 次搜索） | **直接复用本机 Edge 已登录的微软账号**，不需要填邮箱密码，不需要下载任何驱动 |

其他通用能力：

- 顶部「开机自启」开关，**默认开启**，开机后静默在后台签到；
- 每个账号可单独设置每日执行时间；
- 左侧「日志」页实时输出 + 历史记录，失败会写明原因；
- 界面顶部致谢框点击直达各作者仓库；
- 所有数据（数据库、浏览器缓存、日志）都在 `data` 目录，换电脑拷走文件夹即可，删除文件夹即彻底卸载。

## 🖥 环境要求

- Windows 10 / 11（64 位）；
- **必须已安装 Microsoft Edge**（Win10/11 自带，蓝色 e 图标）。本工具**不打包任何浏览器内核**（省掉 600 MB+），网易云与 Bing 都跑在你的 Edge 里；
- 不需要装 Python、Node、JDK，也不下载任何浏览器驱动——运行时全部已内置在压缩包里。

## 🚀 使用方法（小白版，约 3 分钟）

1. **解压**：把 zip 解压到桌面或 D 盘，得到 `AutoCheckinHub2` 文件夹。
2. **打开**：双击文件夹里的 `自动签到助手.exe`，等 3～10 秒会自动弹出一个窗口（没有地址栏，是软件界面本身）。关掉窗口只是关界面，后台服务还在跑，再双击立刻回来。
3. **添加账号**：点右上角「+ 添加账号」，选平台：
   - **网易云音乐**：手机号 + 密码，或被滑块拦下时点「扫码登录」用手机 App 扫一下；
   - **小黑盒**：填站内手机号，收短信验证码填进去（只需一次）；
   - **微软 Bing**：邮箱和密码**都留空**直接保存即可——程序会借用本机 Edge 里已登录的微软账号，1~10 秒显示「登录成功」；只有 Edge 里确实没登录时，才会弹窗让你手动登录一次，之后长期记住。
4. **打开启用开关**：账号右侧「启用」，并确认上方「开机自启」为开启状态。
5. **完事**：每天到点自动签到；想立刻验证就点「立即执行」，然后看「日志」。

## 🔑 账号数量限制（重要）

- **小黑盒：一台电脑只能添加 1 个账号。**
  原因是它的请求签名必须通过内置 Node agent 完成，agent 的登录配置是单份的，同机添加第二个账号会覆盖前一个的登录态，导致两个账号都签不了。
- 网易云音乐、微软 Bing 支持同机多账号（每个账号使用独立的浏览器配置目录）。

---

## ⏰ 关于「电脑要开着」

- 定时签到是**本机进程**跑的，**不是云端服务**：到点时电脑必须处于**开机且未休眠**状态，程序才会执行。
- 关机 / 睡眠 / 休眠期间不会签到，唤醒后不会自动补跑当天的任务（可在唤醒后手动点「立即执行」）。
- 笔记本建议接电源并把「睡眠」设为「从不」；台式机保持开机即可。

## 📐 体积说明（为什么做不到 20 MB）

本版本已不含任何浏览器内核（0 MB），能省的最大一项已经省掉了。剩下的是运行代码本身：

| 组成 | 体积 | 说明 |
| --- | --- | --- |
| Node 运行时 | 90 MB | 小黑盒请求签名只能用 Node 跑，无法用 Python 替代 |
| Python 运行时 | 65 MB | 解释器 20 MB + 精简依赖 45 MB（已删 OpenCV 147 MB、ddddocr 84 MB、onnxruntime 42 MB、numpy 40 MB；已删 Selenium 整套驱动与专属依赖约 9 MB） |
| 小黑盒 agent | 24 MB | 已删 TypeScript 类型等开发依赖 |
| 程序本体 | 0.3 MB | — |

整包 179 MB，压缩成 zip 约 **66 MB**（最初自带 Chromium 的方案是 1331 MB，已缩到约 1/20）。

## ❓ 常见问题

1. **双击没反应？** 确认双击的是 `自动签到助手.exe`；杀毒软件可能拦截，选择「允许运行」；也可看 `data\log\launcher.log`。
2. **端口占用？** 程序会自动顺延（8000 → 8001 …），不影响使用。
3. **提示找不到 Edge？** 说明本机 Edge 被卸载过，去微软官网装回 Microsoft Edge 即可。
4. **Bing 报 `Unable to obtain driver for MicrosoftEdge`？** 这是**旧版**的问题。当前版本已彻底移除 Selenium 与驱动，改用 Playwright 直接驱动本机 Edge，不会再出现该报错。
5. **网易云滑块过不去？** 连续失败会自动转扫码，建议直接用扫码。
6. **小黑盒提示「请求失败或超时：/game/comment/share_data/」？** 这是单次接口超时，不是账号失效。程序会自动换游戏/评价重试 3 次，整轮失败还会自动重跑一次；当天真没补上的任务，第二天会自动跳过已完成项、只补这一项。
7. **登录态过期？** 账号右侧点「重新登录」按提示重来一次即可。
